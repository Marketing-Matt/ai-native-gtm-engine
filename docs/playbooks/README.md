# Operator Playbooks

This folder contains implementation playbooks for the AI-Native GTM Engine.

Each playbook documents how a specific subsystem is designed, implemented, and operated.

Playbooks combine:

- marketing context
- system architecture
- workflow logic
- implementation notes
- lessons learned

The goal is to define what modern marketing engineering looks like in practice.
