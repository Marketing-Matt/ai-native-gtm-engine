# GTM Stack — Build Log & Skill Tracker

> The honest record of building an AI-native marketing capability from scratch.
> Every skill timed, graded, and debriefed. No vanity metrics.

---

## How this works

Every skill built on gtmstack.ai goes through a structured build and debrief process.

**Build session:** Matt and Claude build the skill live. Claude critiques prompts
in real time and validates outputs against real B2B marketing standards.

**Post-build debrief:** At the end of each session, a structured debrief is logged here:
- Time recorded (human thinking time vs total session time)
- Difficulty and effectiveness grades (1–5)
- Prompt quality assessment
- Key learning — one honest observation per build
- What to improve for the next skill

This creates a comparable dataset over time — and genuine content for the community.

---

## Grading rubric

### Difficulty — expertise needed to run the skill

| Grade | Meaning |
|---|---|
| ⭐ 1 | Any marketer, under 30 mins, no prior context needed |
| ⭐⭐ 2 | Basic familiarity with the tactic or tool required |
| ⭐⭐⭐ 3 | Strategic or technical context needed to set up correctly |
| ⭐⭐⭐⭐ 4 | Senior judgment required to configure and interpret output |
| ⭐⭐⭐⭐⭐ 5 | Deep GTM expertise essential — wrong inputs break the output |

### Effectiveness — what AI delivers vs doing it manually

| Grade | Meaning |
|---|---|
| ⭐ 1 | Marginal improvement on manual |
| ⭐⭐ 2 | Useful time saving, quality roughly comparable |
| ⭐⭐⭐ 3 | Significant saving, output quality matches experienced marketer |
| ⭐⭐⭐⭐ 4 | Strong output quality, meaningful strategic value added |
| ⭐⭐⭐⭐⭐ 5 | Transforms what's possible — output exceeds manual capability |

### Prompt quality — assessed by Claude post-build

| Grade | Meaning |
|---|---|
| 🔴 Weak | Vague, missing context, output unreliable |
| 🟡 Developing | Some constraints, but room to sharpen |
| 🟢 Strong | Clear, contextual, output consistently useful |
| ⚡ Excellent | Precise, well-constrained, reusable as-is |
