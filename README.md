# AI-Native GTM Engine

Architecture and experiments for building an AI-native GTM engine from scratch.
---

## The Problem

AI adoption in marketing is often limited not by tools, but by a lack of architectural ownership inside marketing teams.

When data, automation, and AI orchestration are owned outside marketing, execution speed slows and experimentation becomes fragmented.

This project explores how marketing teams can regain technical ownership of their GTM systems.

---

## The Model

The AI-native GTM engine is structured around five layers:

1. Data
2. Intelligence
3. Orchestration
4. Activation
5. Feedback

Each layer represents a capability marketing must understand and partially own.

---

## Repository Structure

This repository documents the evolution of the system.

- `/docs` — core thinking and frameworks
- `/architecture` — diagrams of the GTM engine
- `/experiments` — lab notes and system experiments
- `/workflows` — automation workflows
- `/crm` — audience CRM design
- `/decisions` — architectural decision records
